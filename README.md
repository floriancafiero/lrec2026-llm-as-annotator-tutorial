# lrec2026: llm as annotator tutorial
Materials for the LREC-COLING 2026 tutorial “Under-Resourced Studies of Under-Resourced Languages”: practical, reproducible LLM-as-annotator pipelines for low-resource languages, non-Latin scripts, and historical/OCR corpora, with notebooks, datasets, and ethical guidelines.

## Hands-on notebooks

The practical sessions use five Colab-ready notebooks. They are designed to run in order and include a fallback mode without API keys.
