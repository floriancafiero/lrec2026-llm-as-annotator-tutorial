# Handouts

Short practical resources for participants and instructors.

- `participant_cheatsheet.md`: compact participant-facing checklist.
- `instructor_notes.md`: timing, facilitation notes, fallback plan.
- `colab_troubleshooting.md`: common Colab and notebook issues.

These files are intentionally lightweight Markdown files so they can be read directly on GitHub or converted to PDF before the tutorial.
